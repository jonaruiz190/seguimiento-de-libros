# Seguridad

## Versiones cubiertas

Solo la rama `main` recibe correcciones de seguridad.

## Reportar una vulnerabilidad

No publiques vulnerabilidades, credenciales, datos personales ni pasos de
explotación en un issue público.

Envía el reporte mediante la función **Contactar con soporte** de la aplicación
o mediante un aviso privado al propietario del repositorio. Incluye la
descripción, impacto, pasos mínimos, versión y ruta afectada.

No accedas a datos de otras personas, no interrumpas el servicio y no realices
pruebas destructivas. Se coordinará la divulgación responsable antes de
publicar detalles.

## Secretos

Los archivos `.env`, tokens OAuth, cadenas de conexión y claves de API nunca
deben incluirse en commits, issues, capturas ni registros compartidos.
