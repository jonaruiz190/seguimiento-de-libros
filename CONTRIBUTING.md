# Contribuir

1. Abre un issue para cambios funcionales importantes.
2. Crea una rama desde `main`.
3. No incluyas credenciales ni datos personales.
4. Ejecuta `npm run check`, `npm test` y `npm audit --omit=dev`.
5. Describe el comportamiento, las pruebas y las migraciones en el pull request.

Al contribuir confirmas que tienes derecho a aportar el código y aceptas que se
publique bajo la licencia AGPL-3.0 del proyecto.

Los reportes de seguridad deben seguir `SECURITY.md`, no un issue público.
