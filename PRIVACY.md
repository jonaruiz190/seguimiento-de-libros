# Política de privacidad

Última actualización: 15 de junio de 2026.

Seguimiento de Libros almacena los datos necesarios para operar la cuenta:
nombre, nombre de usuario, correo, contraseña protegida mediante hash,
preferencias, seguimientos de lectura, foto de perfil y conexiones opcionales.

Las contraseñas no se almacenan en texto plano. Los tokens OAuth se cifran en
el servidor. Los datos se alojan en proveedores de infraestructura y solo se
comparten cuando es necesario para prestar el servicio o cumplir la ley.

El usuario puede editar o eliminar su cuenta desde la aplicación. La
eliminación borra los datos asociados, salvo copias temporales de respaldo que
expiren conforme a la retención del proveedor.

No deben enviarse contraseñas, claves API ni información sensible mediante el
formulario de soporte.

Antes de abrir el servicio al público general, este documento debe revisarse
con asesoría legal y completarse con una dirección de contacto válida.
